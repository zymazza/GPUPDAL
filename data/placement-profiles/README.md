# Shipped placement profiles (D0279)

Every `*.json` file here is embedded into the engine at build time
(`ShippedProfilesData.cpp`, generated by `src/CMakeLists.txt`) and consulted by
`placementCalibrationFor` after the embedded reference profile and any local
`pdg calibrate` profile:

- `tier: "shipped"` — a GPU-class profile measured by `pdg calibrate` on a
  rented machine with that GPU (`bench/remote/vast_sweep.sh`) and converted by
  `bench/report/make_shipped_profile.py`, which keeps only the stage models
  whose device win cleared the shipping margin (1.7x, D0280) at every
  measured size and bounds the envelope to those sizes. Keyed by exact device
  name, compute capability and compiled CUDA toolkit; the host it was
  measured on is recorded under `machine` for evidence, not matched.
- `tier: "generic"` — the conservative fallback for any other CUDA device
  (`make_shipped_profile.py --generic`): the intersection of the shipped
  profiles' models that clear a 3x margin in every profile (an unknown GPU may
  be slower than the slowest swept class), the slowest device
  and fastest host coefficients seen, and `applies` bounds from the smallest
  compute capability and device memory among them.

Regenerate a file only from a calibrate run's profile (with its evidence);
never edit numbers by hand. Evidence: BENCHMARKS.md B0278.
