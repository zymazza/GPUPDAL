# Canonical third-party license texts

This directory retains license texts needed by source components whose files
carry short-form notices:

- `Apache-2.0.txt` is the SPDX canonical Apache License 2.0 text used by H3,
  LEPCC, parts of laz-perf, and other attributed sources.
- `MPL-2.0.txt` is the SPDX canonical Mozilla Public License 2.0 text used by
  Eigen sources.

Component-specific copyright notices remain in their source files and in
`NOTICE`. The release bundle copies these texts together with the MIT and
Boost-1.0 license files already retained by their vendored components.
