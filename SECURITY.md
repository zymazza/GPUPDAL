# Security policy

## Supported versions

GPUPDAL has not published its first release. Security fixes currently target
the latest commit on `main`; a version-support table will be added before the
first public release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory reporting for this repository or email **zy@automagics.com**
with `GPUPDAL SECURITY` in the subject. Include the affected command or parser,
a minimal non-sensitive reproducer, impact, and the GPUPDAL and pinned-PDAL
versions. Do not email secrets or private datasets unless a secure transfer
method has been agreed first.

GPUPDAL aims to acknowledge security reports within five business days. This
is a best-effort open-source project target, not a service-level agreement,
support contract, warranty, or promise that a fix will be available. The
software remains provided **AS IS**, without warranties, under
[LICENSE.txt](LICENSE.txt).
